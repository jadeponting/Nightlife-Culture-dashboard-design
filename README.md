# Dashboard Design — the research book

**How dashboards work, and why — the methodological and theoretical foundation behind the Vibe Map's evidence displays.**

Nightlife Culture · Carly Heath · started 16 August 2026 · version 2 from 5 October 2026

---

## What this is

A research book that teaches someone meeting the subject for the first time how evidence is turned into a display a reader can trust, read and act on — and what it costs when that is done badly. It is the third of the studio's foundations:

| Foundation | Answers | Lives |
|---|---|---|
| The Decision Book (`design-decisions`) | How to choose | `~/Documents/GitHub/decision-book` |
| The design system (`nightlife-culture-design`, Style Guide v1.5) | What the values are | `~/Documents/GitHub/Nightlife Culture Design System` |
| **This book** | **How evidence becomes a display that steers a decision** | here |

It serves the Vibe Map prototype — a living, interactive account of the people, activity, value and support systems that sustain a place's nightlife culture — but it is not an assessment, a specification or a design of it. The prototype's own records live in `vibe-map-prototype` and `vibe-map-ukdf-scope`.

A dashboard, in this book, is *a display that turns data into a decision for a named reader*. The book asks what a dashboard does, why it matters, what is risked when it is done poorly, what is gained when it is done well, how any of that is proved — and, running through all of it, how one might measure a vibe.

## Rules that travel with the repository

The book never researches nightlife; that is Carly's knowledge and enters as the frame. It never answers the prototype's questions about actual places. It never makes the creative decisions. Confidential material is cited, never reproduced. Agents never commit; Carly reviews and commits.
