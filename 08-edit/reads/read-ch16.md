### B. What the chapter teaches

The chapter answers one question: when a rule in this book is to be broken, how is it done well. It decides that the Decision Book's three-tier test holds but that the book has been misusing "Fixed" to mean "important"; it writes the four kinds of deviation (ignorant, lazy, expedient, earned) the house named but never defined; it derives a nine-line deviation entry from twelve regimes in other fields and from the evidence on when a written reason helps; it shows from clinical override data that a rule set where everything is Fixed is read as noise; and it collapses the book's twelve records into one record and its three logs into one log, handing the build a register and four checks. A newcomer (a creative technologist or analyst joining the build) would take away: find the tier first; a departure is earned by timing, specificity, a test and a reader, not by the record alone; keep the Fixed list short and let the build enforce it; give every entry a review date.

Best passages, which must survive any edit:
- Lines 120–128, the four kinds of deviation. Concrete, each class tied to a regime's own words and a measured failure ("the entry — if there is one — is a space", line 122; the re-write of version 1's gloss at line 128).
